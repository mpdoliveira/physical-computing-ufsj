# Physical Computing — Exercises and Projects

Repository containing exercises and projects developed for Physical Computing coursework at the **Federal University of São João del-Rei (UFSJ)**.

## What I Built

- **Arduino fundamentals:** exercises with LEDs, RGB color control, traffic-light sequences, push buttons, and potentiometers using digital and analog inputs and outputs.
- **Button debouncing:** improvement of a push-button example to handle input noise and prevent unintended LED state changes.
- **Potentiometer library:** an Arduino C++ library for reading analog values, converting readings to voltage, and mapping them to custom ranges, with an example sketch.
- **ESP32 Air Mouse:** adaptation and study of an [open-source Air Mouse project](https://github.com/TechTalkies/YouTube/tree/main/48%20ESP32%20Air%20Mouse) using an ESP32, an MPU6050 motion sensor, Bluetooth Low Energy, and two buttons for mouse clicks. See the [project documentation](4.public_projet_air_mouse/README.md) for the implementation and library analysis.

## Learning Objectives

Apply physical computing concepts through hands-on work with embedded programming, digital and analog I/O, PWM, sensor readings, input debouncing, Arduino library development, I²C communication, and Bluetooth connectivity.

## Technologies and Tools

**Languages:** C/C++ (Arduino).

**Hardware:** Arduino Uno, ESP32, MPU6050, LEDs, potentiometers, and push buttons.

**Libraries and tools:** Arduino IDE, Adafruit MPU6050, ESP32 BLE Mouse, Wire (I²C), and Git/GitHub.
